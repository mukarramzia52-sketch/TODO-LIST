## 👋 About this project

This is my first solo project built entirely with **vanilla HTML, CSS, and JavaScript** — no frameworks, no shortcuts. I wanted to prove to myself (and show recruiters) that I understand what's actually happening under the hood before reaching for a library.

Every feature below — the drag-and-drop, the dark mode, the async storage — was built from first principles.

## ✨ What it does

| Feature | Description |
|---|---|
| 📝 **Add / Edit / Delete** | Double-click any task to edit it inline |
| ☑️ **Mark complete** | One click to check off a task |
| 🔀 **Drag & drop** | Reorder your list by dragging tasks around |
| 🔍 **Live search** | Find tasks instantly as you type |
| 🗂️ **Filters** | View all, completed, or incomplete tasks |
| 🌗 **Dark mode** | Toggle theme, remembered across visits |
| 📤 **Export / Import** | Back up or restore your list as JSON |
| 💾 **Persistent storage** | Tasks are saved in `localStorage`, no backend needed |

## 🧠 Skills demonstrated

- **DOM manipulation** without a framework — creating, updating, and removing elements manually
- **Asynchronous JavaScript** — wrapped `localStorage` in Promises and used async/await throughout
- **Event handling** — forms, clicks, keyboard input, and the native Drag & Drop API
- **State management** — kept the UI in sync with a plain JavaScript array, no libraries
- **Clean, readable code** — organized into clear sections so anyone can follow the logic

## 📌 Why this matters

Frameworks are great, but understanding the fundamentals underneath them is what separates someone who copies tutorials from someone who can actually debug, extend, and reason about code. This project is proof of that foundation.
